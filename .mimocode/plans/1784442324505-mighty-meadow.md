# План: Туториал с комикс-панелями

## Инструмент
Leonardo.ai (бесплатно, 150 изображений/день). Character Reference для консистентности кота.

## Шаг 1: Создать Character Reference
Промпт: `A cute cartoon cat character, orange fur, big green eyes, friendly smile, standing on two legs, chibi/kawaii style, flat design, child-friendly, white background, full body, no text`

Модель: Leonardo Diffusion XL / Phoenix
Style: Anime / Illustration
Negative: realistic, dark, scary, violence, text

## Шаг 2: Сгенерировать 6 панелей
Для каждой: загрузить базового кота как Character Reference + описать сцену.

1. Кот машет лапой — "Привет! Я — Кот-учёный!"
2. Ребёнок и родитель по бокам — "Кто ты?"
3. Кот за столом с книгами — "Вот твои уроки"
4. Кот ловит кристаллы — "Реши задачу — заработай!"
5. Кот в уютной комнате — "Твоя комната"
6. Кот с джойстиком — "Открывай игры!"

## Шаг 3: Интеграция в код
- Изображения → `public/tutorial/`
- Новый компонент `src/app/components/Tutorial.tsx` — свайп-карусель
- Показывается при первом запуске (проверка `TUTORIAL_KEY` в localStorage)
- После прохождения — скрывается навсегда

## Ключевые файлы
- `src/app/components/Tutorial.tsx` (новый)
- `src/app/App.tsx` (добавить показ туториала при старте)
- `public/tutorial/` (папка с изображениями)

## Верификация
1. Сгенерировать 6 изображений в Leonardo.ai
2. Положить в public/tutorial/
3. Запустить Vite, проверить что туториал показывается при первом запуске
4. Проверить что после прохождения больше не показывается
