# Tutorial Images

Generate these 6 images using Leonardo.ai (or Midjourney/DALL-E).

## Character Reference
First generate your BASE cat character:
```
A cute cartoon cat character, orange fur, big green eyes, friendly smile, 
standing on two legs like a child, wearing a tiny purple wizard hat, 
chibi/kawaii style, flat design, child-friendly, educational app mascot, 
white background, full body, no text
```

Save as: `cat_base.webp`

## Settings for Leonardo.ai
- Model: Leonardo Diffusion XL or Phoenix
- Style: Anime (or Illustration)
- Resolution: 1024x1024 (1:1)
- Negative prompt: realistic, dark, scary, violence, blood, text, watermark
- Guidance: 7
